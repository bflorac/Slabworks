SlabWorks Help

Important: SlabWorks creates raw toolpaths and does not utilize any vectors in the drawing. You cannot edit the toolpaths once created. If you need to modify them, you should delete and recreate the toolpaths with your new settings.

Slab Dimensions

Slab Width
The width of the workpiece in inches.
Slab Height
The height of the workpiece in inches.
Slab Thickness
The thickness of the workpiece material in inches.

Tool Settings

Quick Tool Presets: Use the preset buttons to automatically populate tool settings for common bits:
  • 6210 - Whiteside, 1" diameter, ¼" shank, 3 flutes
  • 6220 - Whiteside, 2" diameter, ½" shank, 4 flutes
  • RC2255 - Amana, 2" diameter, ½" shank, 3 flutes
Bit Diameter
The diameter of your cutting bit in inches. This affects the toolpath calculations and stepover distance.
Spindle RPM
The rotational speed of the spindle in revolutions per minute.
Stepover
The lateral distance between adjacent toolpath passes in inches, typically expressed as a percentage of bit diameter or actual distance.

Toolpath Configuration

Toolpath Type
Select the pattern for material removal:
  • Linear Y - Straight passes along the Y axis
  • Linear X - Straight passes along the X axis
  • Climb Only - Unidirectional cutting in the optimal climb direction
  • Spiral - Rectangular spiral pattern from outside to center
  • True Spiral - Continuous curved spiral pattern
Perimeter Cut First
When enabled, the outer perimeter is cut before the internal toolpaths. This can help define workpiece boundaries and reduce tear-out.
Note: Only applies to Linear X and Y toolpath types.
Alternate Tool Number to Force Tool Change Stop
When enabled, inserts a tool change command to pause the machine, allowing for inspection of the workpiece during the cutting operation.

Cutting Parameters

Repeat
Number of times to repeat the cutting pass. This value is automatically calculated based on Depth ÷ Cut Depth, or you can enter it directly to update the Depth value.
Depth
The total depth of the cut operation in inches. This equals Repeat × Cut Depth and updates automatically when either value changes.
Depth Offset
Starting depth offset from the workpiece surface in inches. Use this to account for material already removed in a previous run, avoiding cutting air. This value defaults to the Depth from the previous run.
Cut Depth
The depth of material removed in each pass in inches. Multiple passes will be generated if this is less than the total depth.
Feedrate
The speed at which the cutting tool moves through the material in inches per minute.
Home Height
The height in inches above the workpiece where program will start and end.
Important: Before running your toolpath, ensure your work coordinate system home is set to the lower left of your workpiece with Z-zero at the top surface.
